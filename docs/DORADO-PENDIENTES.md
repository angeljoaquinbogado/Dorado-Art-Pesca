# Dorado — datos pendientes del comercio

La web queda preparada sin inventar estos datos. Antes del lanzamiento real confirmar:

- Email comercial para confirmaciones automáticas.
- Domicilio escrito exacto del local (el sitio ya usa el link de Google Maps suministrado).
- Empresa/s de transporte y condiciones de envío nacional.
- Datos de la cuenta de Mercado Pago del comercio para Producción.
- Datos de transferencia si se desean mostrar automáticamente en vez de coordinarlos por WhatsApp.
- Confirmar nombre del responsable del negocio antes de publicarlo en la sección Nosotros.

Mientras tanto, transferencia y efectivo se coordinan por WhatsApp; efectivo se limita a retiro.
