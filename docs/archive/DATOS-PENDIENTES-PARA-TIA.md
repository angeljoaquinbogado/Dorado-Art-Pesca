## Falta confirmar con la tienda

### 1. Email comercial
Crear un correo exclusivo para Dorado. Se usará para el panel Admin, confirmaciones de pedidos y contacto comercial.

### 2. Mercado Pago
Confirmar qué cuenta de Mercado Pago usará el comercio. Después se configuran credenciales de producción, webhook y firma. Hasta ese momento MP queda deshabilitado en la web.

### 3. Envíos
Confirmar:
- qué transportes/correos usan;
- si hacen entrega local;
- zonas cubiertas;
- cómo se calcula el costo;
- tiempos estimados;
- quién paga el envío en cambios voluntarios.

### 4. Políticas definitivas
La web ya incluye una versión provisoria razonable. La tienda debe revisar especialmente cambios voluntarios, devoluciones, fallas y logística antes del lanzamiento completo.

### 5. Catálogo real
Cuando el email Admin esté listo, cargar desde `/admin.html`:
- nombre del producto;
- categoría;
- descripción y características;
- precio;
- stock;
- imágenes;
- estado activo/oculto.

## Recomendado antes de vender públicamente

- Confirmar datos de facturación del comercio si corresponde publicarlos o usarlos en comprobantes.
- Hacer una compra real de importe bajo de punta a punta.
- Verificar confirmación, stock, seguimiento, correo y estado del pedido.
